Faire communiquer 2 cartes entre-elles

Voici le code que nous avons créé pour faire communiquer les cartes :

Le code ci-dessus est le même pour les deux cartes utilisées.

Il peut être décomposé en 2 parties principales :

  • Le bloc d'initiation
  • Les blocs de condition

Le bloc d'initiation

Le bloc d'initiation permet tout d'abord de connecter les deux cartes entre elles.

Pour ce faire, nous créons une liaison radio, appelé ici 66

Ensuite, plusieurs options s'offrent à nous choisir d'écrire des mots dans les variables que l'on va initier ou choisir d'écrire des caractères.

Ici nous vous présentons le mode avec caractère car il permet contrairement à l'autre mode de pouvoir communiquer uniquement à l'aide des cartes à condition de connaitre son code morse.

C'est beaucoup plus pratique que de réécrire fastidieusement des mots à chaque fois. # démonstration

Les blocs de conditions

Les blocs de conditions servent à choisir quel caractère envoyer

Le bouton A envoie un point. Le bouton B est un tiret. Lorsque les boutons A et B sont cliqués au même moment, l'écran devient vierge, utile pour enchaîner deux fois le même caractère.

Le dernier bloc permet de montrer ce qui est reçu depuis la liaison radio précédemment établie.

Ainsi, en téléchargeant ce code sur 2 cartes, elles peuvent communiquer entre elles
